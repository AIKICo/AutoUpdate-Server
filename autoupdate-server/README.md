# راهنمای وب‌سرور اختصاصی AutoUpdate-Server (مبتنی بر C)

این وب‌سرور یک سرویس فوق‌العاده سبک، سریع و کاملاً **مستقل (Standalone)** است که با زبان C توسعه داده شده و به صورت کامپایل استاتیک (بدون وابستگی به هیچ پکیج، اینترنت یا کتابخانه اشتراکی سیستم‌عامل) آماده اجرا بر روی تمامی توزیع‌های لینوکس ۶۴ بیتی (CentOS, Ubuntu, Debian, RHEL, Rocky, Alpine و ...) می‌باشد.

این سرور به‌طور اختصاصی برای سناریوی به‌روزرسانی نرم‌افزارها با کتابخانه **[AutoUpdater.NET](https://github.com/ravibpatel/AutoUpdater.NET)** بهینه‌سازی شده است.

---

## ویژگی‌های کلیدی

1. **پشتیبانی کامل از Resume (دانلود قطعه‌ای / Range Requests):**
   - پشتیبانی از استانداردهای HTTP `Accept-Ranges: bytes` و `Range: bytes=start-end` با کد وضعیت `206 Partial Content`.
   - در صورت قطعی یا کندی اینترنت کلاینت‌ها، دانلود فایل‌های نصبی حجیم (`.exe`, `.zip`, `.msi`) متوقف نشده و کلاینت دانلود را از همان نقطه قطعی ادامه می‌دهد.
2. **سرعت ماکزیمم با Zero-Copy Kernel sendfile:**
   - استفاده از فراخوان مستقیم هسته لینوکس `sendfile(2)` جهت انتقال داده مستقیماً از حافظه نهان دیسک به کارت شبکه بدون کپی داده در فضای حافظه برنامه.
   - حداقل مصرف رم (زیر ۱۵ مگابایت حتی هنگام دانلود همزمان ده‌ها کلاینت).
3. **رابط کاربری مدیریتی تحت وب (Web Dashboard):**
   - پنل مدیریتی مدرن، زیبا و کاملاً مستقل و آفلاین در آدرس `/admin/`.
   - تولید خودکار و آنی فایل‌های کانفیگ `AutoUpdater.xml` و `AutoUpdater.json`.
   - امکان آپلود مستقیم فایل‌های نصبی از طریق مرورگر.
   - محاسبه خودکار هش SHA-256 و MD5 فایل‌ها جهت تایید سلامت فایل در کلاینت.
   - مانیتورینگ زنده ترافیک، مدت زمان فعالیت و درخواست‌ها.
4. **عملکرد پایدار در پس‌زمینه (Daemon Mode):**
   - امکان اجرای دائم در پس‌زمینه با سوییچ `-d` یا اسکریپت‌های مدیریت.
   - مدیریت PID و مهار خطای قطع اتصال کلاینت‌ها (`SIGPIPE`).
   - ارائه فایل سرویس `systemd` برای اجرای خودکار هنگام بالا آمدن سرور لینوکس.
5. **امنیت بالا:**
   - جلوگیری قاطع از حملات نفوذ به دایرکتوری‌های خارج از مسیر سرور (Directory Traversal Prevention).

## ساختار دایرکتوری

```
autoupdate-server/
├── bin/
│   └── autoupdate-server     # فایل اجرایی باینری استاتیک لینوکس (بدون نیاز به نصب)

│   └── admin/
│       └── index.html        # فایل قالب رابط کاربری وب
├── updates/                  # پوشه نگهداری فایل‌های نصبی و کانفیگ‌های AutoUpdater
│   ├── AutoUpdater.xml       # کاتالوگ XML برای AutoUpdater.NET
│   ├── AutoUpdater.json      # کاتالوگ JSON برای AutoUpdater.NET
│   └── changelog.html        # گزارش تغییرات نسخه
├── config.ini                # تنظیمات پورت و مسیرها
├── autoupdater.service       # فایل سرویس systemd جهت شروع خودکار لینوکس
├── start.sh                  # اسکریپت راه‌اندازی سریع در پس‌زمینه
├── stop.sh                   # اسکریپت توقف سرور

└── Makefile                  # فایل کامپایل مجدد در صورت نیاز
```

## نحوه انتقال و راه‌اندازی روی سرور لینوکس آفلاین

### ۱. انتقال فایل‌ها به لینوکس
پوشه `autoupdate-server` را از طریق فلش مموری یا نرم‌افزار WinSCP / SFTP به سرور لینوکس (مثلاً مسیر `/opt/autoupdate-server` یا پوشه خانگی خود) منتقل کنید.

### ۲. اعطای مجوز اجرا به فایل‌ها
در ترمینال لینوکس دستورات زیر را اجرا کنید:
```bash
cd /path/to/autoupdate-server
chmod +x ./bin/autoupdate-server start.sh stop.sh status.sh
```

### ۳. راه‌اندازی در پس‌زمینه (روش ۱ - با اسکریپت)
```bash
./start.sh
```

### ۴. راه‌اندازی با دستور مستقیم (روش ۲ - خط فرمان)
```bash
# اجرا روی پورت 8080 در پس‌زمینه:
./bin/autoupdate-server -d -p 8080 -w ./updates -r ./webroot

# اجرا روی هر پورت دلخواه دیگر (مثلاً 9090):
./bin/autoupdate-server -d -p 9090 -w ./updates -r ./webroot
```

### ۵. بررسی وضعیت سرور
```bash
./status.sh
# یا:
./bin/autoupdate-server status
```

### ۶. توقف سرور
```bash
./stop.sh
# یا:
./bin/autoupdate-server stop
```

## ورود به پنل مدیریت تحت وب

پس از اجرای سرور، مرورگر خود را باز کرده و به آدرس زیر بروید:
```
http://<آدرس-آی‌پی-سرور-شما>:8080/admin/
```

- **نام کاربری پیش‌فرض:** `admin`
- **کلمه عبور پیش‌فرض:** `admin123`
*(این مقادیر در فایل `config.ini` یا از طریق پارامترهای خط فرمان `-u` و `-a` قابل تغییر هستند).*

در این پنل می‌توانید:
1. فایل نصبی برنامه خود (`Setup.zip` یا `Setup.exe`) را آپلود کنید.
2. مقدار هش SHA-256 فایل به صورت خودکار محاسبه و نمایش داده می‌شود.
3. با تکمیل شماره نسخه جدید و کلیک بر روی دکمه «تولید»، فایل‌های `AutoUpdater.xml` و `AutoUpdater.json` خودکار ساخته می‌شوند.

## استفاده در پروژه دات‌نت (C# / AutoUpdater.NET)

در برنامه سی‌شارپ خود کافیست کدهای زیر را قرار دهید:

```csharp
using AutoUpdaterDotNET;

// رویداد بررسی به‌روزرسانی (مثلاً در Form_Load یا App.xaml.cs)
public void CheckForUpdates()
{
    // آدرس سرور لینوکسی شما:
    AutoUpdater.Start("http://192.168.1.100:8080/AutoUpdater.xml");

    // در صورت تمایل به دریافت نگارش JSON:
    // AutoUpdater.Start("http://192.168.1.100:8080/AutoUpdater.json");
}
```

کتابخانه `AutoUpdater.NET` به صورت خودکار نسخه جاری برنامه را با فایل XML روی سرور مقایسه کرده و در صورت وجود نسخه جدیدتر، فایل نصبی را با سرعت بالا و قابلیت ادامه دانلود (Resume) دریافت و نصب می‌کند.

## راه‌اندازی به عنوان سرویس سیستمی دائم (Systemd Service)

برای این که سرور با ریبوت شدن لینوکس به طور خودکار بالا بیاید:

1. پوشه را به مسیر استاندارد `/opt/autoupdate-server` منتقل کنید:
   ```bash
   sudo cp -r autoupdate-server /opt/
   ```
2. فایل سرویس را کپی و فعال کنید:
   ```bash
   sudo cp /opt/autoupdate-server/autoupdater.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable autoupdater
   sudo systemctl start autoupdater
   ```
3. بررسی وضعیت سرویس:
   ```bash
   sudo systemctl status autoupdater
   ```

## تنظیم فایروال لینوکس (در صورت نیاز)

اگر فایروال سرور فعال است، پورت وب‌سرور را باز کنید:

- در توزیع‌های مبتنی بر **UFW** (اوبونتو / دبیان):
  ```bash
  sudo ufw allow 8080/tcp
  ```
- در توزیع‌های مبتنی بر **Firewalld** (سنت‌او‌اس / RHEL / رادکی لینوکس):
  ```bash
  sudo firewall-cmd --permanent --add-port=8080/tcp
  sudo firewall-cmd --reload
  ```
