# راهنمای Nginx پرتابل برای لینوکس بدون نیاز به اینترنت و نصب

این پکیج شامل نسخه **استاتیک رسمی Nginx** (نسخه ۱.۲۶.۲ برای لینوکس x86_64) است که بدون کوچکترین نیازی به اینترنت، پکیج منیجر (`apt`, `yum`) یا لایبرری‌های جانبی بر روی سرور لینوکس اجرا می‌شود.

این بسته با کانفیگ بهینه‌سازی شده ویژه تحویل فایل‌های به‌روزرسانی برای کتابخانه **[AutoUpdater.NET](https://github.com/ravibpatel/AutoUpdater.NET)** پیکربندی شده است.

---

## ویژگی‌های پیکربندی Nginx

- **فعال بودن `sendfile` و `tcp_nopush`:** ماکزیمم سرعت دانلود با انتقال مستقیم Zero-Copy در سطح هسته لینوکس.
- **پشتیبانی کامل از سرآیند `Accept-Ranges: bytes`:** امکان ادامه دانلود (Resume) قطعه‌ای در کلاینت AutoUpdater.NET هنگام قطعی شبکه.
- **پیکربندی خودکار CORS:** هدرهای `Access-Control-Allow-Origin: *` برای رفع محدودیت دسترسی کلاینت‌ها.
- **جلوگیری از کش مانیفست‌ها:** فایل‌های `AutoUpdater.xml` و `AutoUpdater.json` بدون کش شدن ارائه می‌شوند تا کلاینت‌ها همیشه آخرین نگارش را دریافت کنند.
- **فعال‌سازی `autoindex`:** نمایش فهرست فایل‌ها در مرورگر در آدرس ریشه.

## ساختار پوشه‌ها

```
nginx-portable/
├── sbin/
│   └── nginx           # باینری استاتیک لینوکس ۶۴ بیتی Nginx
├── conf/
│   ├── nginx.conf      # فایل تنظیمات بهینه‌شده
│   └── mime.types      # انواع فرمت‌های فایل
├── updates/            # پوشه قرارگیری فایل‌های نصبی و کانفیگ‌ها
│   ├── AutoUpdater.xml
│   └── AutoUpdater.json
├── logs/               # فایل‌های لاگ خطا و دسترسی
├── start.sh            # اسکریپت اجرای در پس‌زمینه
├── stop.sh             # اسکریپت متوقف‌سازی
├── reload.sh           # اعمال مجدد تنظیمات بدون قطعی
└── status.sh           # بررسی وضعیت اجرا
```

## نحوه اجرا در سرور لینوکس

1. پوشه `nginx-portable` را با WinSCP یا فلش مموری به سرور لینوکس منتقل کنید.
2. دسترسی‌های اجرایی را فعال کنید:
   ```bash
   cd /path/to/nginx-portable
   chmod +x ./sbin/nginx start.sh stop.sh reload.sh status.sh
   ```
3. اجرای Nginx در پس‌زمینه:
   ```bash
   ./start.sh
   ```
4. مشاهده وب‌سرور در مرورگر یا کلاینت:
   ```
   http://<آدرس-آی‌پی-سرور>:8080/
   ```
5. توقف Nginx:
   ```bash
   ./stop.sh
   ```

## نحوه تغییر پورت شنود

برای تغییر پورت از `8080` به هر پورت دیگری (مثلاً `80` یا `9000`):
فایل `conf/nginx.conf` را باز کرده و خط زیر را ویرایش کنید:
```nginx
listen       8080;
```
سپس دستور زیر را برای اعمال تغییرات اجرا کنید:
```bash
./reload.sh
```
*(توجه: استفاده از پورت‌های زیر 1024 مانند پورت 80 نیازمند دسترسی روت یا sudo است).*
